# Jyoti AI Marketing

Standalone starter repo for Jyoti Gruh Udhyog's AI marketing system.

## MVP included
- Marketing dashboard
- Product poster generator
- Occasion/daily marketing calendar
- Review marketing placeholder for the existing review system
- Social publishing connection placeholders
- Analytics placeholder

## Next integrations
1. AI image/content generation API
2. Existing Jyoti review system API/webhook
3. Meta Graph API for Facebook/Instagram publishing
4. WhatsApp Business Platform/API
5. Database + authentication
6. Real analytics and scheduled jobs

This starter is intentionally independent from the existing Jyoti Digital Menu repository.
